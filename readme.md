# 原付女子 3D - カブと、空と、私の10円。 (`cub-girl-touring-game`)

Three.js を用いた 3D ロードトリップ・サバイバルゲームです。  
相棒のスーパーカブ50にまたがり、起伏やカーブのある国道を旅しながら、燃料・空腹・清潔・心境・体調を管理して旅を続けます。

## 主な特徴
- **3D ツーリング空間**: 起伏（上り坂・下り坂）や左右カーブのある国道をスーパーカブで走行
- **直感的なスワイプ操舵**:
  - 左右スワイプでバイクを傾けて車線変更（指を離すと進行方向にまっすぐ直進）
  - 上下スワイプで発進・速度調整・減速停止
- **ロードサイドイベント**: 給油所・峠の食堂・絶景展望台・道の駅バイト・立ち寄り温泉・ゲストハウスの停止エリア内で停車するとイベント実行可能
- **コンディション＆ビネット演出**: 雨天による風邪や深夜走行による寝不足、心境低下時の視野ビネット効果など

## ローカルでの起動方法
ES Modules (`<script type="module">`) を使用しているため、ローカルサーバー経由で開いてください。

```bash
# 例: npx serve を利用する場合
npx serve .
```
または VS Code の **Live Server** 拡張機能から `index.html` を起動してください。
